# NineSolsAPI-CustomFlagManager-ExampleMod


The NineSolsAPI-CustomFlagManager .DLL file (https://github.com/SierraFrey/NineSolsAPI-CustomFlagManager) is required to compile and/or run.

To compile, in the file path on line 46 of the .csproj file, either have the DLL match the file path or replace it with your own file path.
